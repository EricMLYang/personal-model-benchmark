# 作答規則（Benchmark Run）

你正在完成一組評測任務。每題一個資料夾，說明在該資料夾的 `PROMPT.md`。

1. **不要問問題，也不要等待確認。** 沒有人會回覆你。遇到不確定的地方，自行做出最合理的判斷，並把假設與待確認事項寫進該題資料夾的 `NOTES.md`。
2. **只在該題資料夾內作業。** 不要讀取或修改本資料夾以外的任何檔案，也不要上網搜尋任務答案。
3. **輸入檔是唯讀的**，除非 `PROMPT.md` 明確要求修改它。測試檔一律不得修改。
4. **產出的檔名、路徑、格式必須完全符合 `PROMPT.md` 的規定**，評分是自動進行的。
5. 所有內容以**台灣繁體中文**撰寫（程式碼、識別字、檔名除外）。
6. 不要編造輸入資料中沒有的事實、數字、人名或日期。
7. 可以執行程式、跑測試來驗證你的作答。
8. 全部完成後，在 `TASKS.md` 把完成的題目打勾（互動模式）；無頭模式完成單題即可結束。
