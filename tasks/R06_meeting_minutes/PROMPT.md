# 任務：把會議逐字稿整理成會議紀錄

`transcript.md` 是一場會議的語音轉文字逐字稿（口語、有插話、有改口）。請整理成會議紀錄。

## 產出 1：`minutes.json`（評分用，格式必須完全一致）

```json
{
  "meeting_date": "YYYY-MM-DD",
  "tldr": "三句話以內的摘要",
  "decisions": [
    {"text": "最終確定的決策"}
  ],
  "actions": [
    {"owner": "負責人姓名", "task": "要做的事", "due": "YYYY-MM-DD"}
  ],
  "open_questions": [
    {"text": "提出了但沒有結論、或沒有負責人的事項"}
  ]
}
```

規則：

- `decisions` 只列**最終**確定的決策；會中被推翻、撤回的不列。
- `actions` 只列**有明確負責人**的行動項；負責人以最終定案的人為準。
- `due` 一律換算成絕對日期（`YYYY-MM-DD`），依會議日期推算「明天」「這週五」「下週三」等說法；期限以最後一次確認的為準。
- 沒有負責人的提議放進 `open_questions`，不要自己指派負責人。
- 不要加入逐字稿沒有的內容。

## 產出 2：`minutes.md`

給沒參加會議的主管看的會議紀錄：TL;DR、決策、行動項表（負責人／事項／期限）、待決事項。
