# 任務：看板試播數據問答＋給客戶 PM 的短報告

`data/` 內是連鎖門市數位看板兩週試播的資料，資料字典與**計算規則**在 `data/README.md`，請務必遵守。

## 第一部分：`answers.json`

回答下列 10 題，寫成 `answers.json`，格式 `{"Q01": 值, ..., "Q10": 值}`。
數值題四捨五入到小數第 2 位（整數題給整數）；百分比題給「百分比數值」（例如 12.34 代表 12.34%）；文字題給完全相同的代號或名稱。

| 題號 | 問題 |
|------|------|
| Q01 | 期間內總曝光人次是多少？ |
| Q02 | `plays.csv` 中因重複上傳而多出來的列數是多少？（以全檔計算，不排除關店） |
| Q03 | 哪一個店型（`store_type`）的營收合計最高？ |
| Q04 | 辦公型門市在午餐時段的「平均每店每日營收」是多少？（＝營收合計 ÷（營業中辦公型門市數 × 14 天）） |
| Q05 | 受眾包 P03 的時段對齊率（%）是多少？ |
| Q06 | 「每千次曝光目標品類營收」最高的是哪一個受眾包？（填代號，如 P01） |
| Q07 | 承 Q06，該受眾包的每千次曝光目標品類營收是多少？ |
| Q08 | 南區晚餐時段的客單價是多少？ |
| Q09 | 咖啡品類第二週營收相較第一週的成長率（%）是多少？ |
| Q10 | `sales.csv` 中營收空白、被排除的列數是多少？（以全檔計算，不排除關店） |

## 第二部分：`report.md`

寫一份給**客戶端專案經理**看的短報告（全文 800 字以內），必須包含三個小節，標題依序為：

1. `## 重點發現`
2. `## 受眾包表現`
3. `## 資料品質提醒`

要求：報告中出現的每一個數字都必須能從資料算出來（不要估計、不要編造）；資料品質提醒要說清楚排除了什麼、排除了多少。

## 其他

可以寫程式（Python + pandas 可用），程式放在本資料夾即可。評分看 `answers.json` 與 `report.md`。
