# eventcal

追蹤各上市公司的法說會日期，並決定下一次要去哪段時間找法說會公告。

## 規則

1. **所有日期判斷一律以台灣時間（UTC+8）為準。** 美股、日股等公告時間帶各自時區，進系統後要先轉成台灣日期，再判斷屬於哪一天、哪一季。
2. 季度以日曆季度計。
3. **財年以「結束年份」命名**：財年 4 月起的公司，2026-04-01 ~ 2027-03-31 是 FY2027，2026 年 5 月屬於 FY2027Q1；財年 1 月起的公司，財年就是日曆年。
4. 同一家公司同一天（台灣日期）只記一場法說會。
5. 搜尋窗口：
   - 有歷史：上次法說日 + 91 天為預期日，前後各 14 天。
   - 冷啟動（沒有歷史）：今天所在財季的季末 + 各市場延遲天數為預期日。
