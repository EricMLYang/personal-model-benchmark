# 任務：修正 eventcal 的日期問題

本資料夾是一個小型 Python 專案 `eventcal`（規則見 `README.md`）。使用者回報了下面這張 issue，請找出根因並修正。

---

**Issue #42：搜尋窗口季度算錯、冷啟動財年標籤錯**

1. 美股公司 NovaChip 在美東時間 2026-03-31 19:00（`2026-03-31T19:00:00-04:00`）開法說，台灣時間其實是 4/1 早上。
   系統把這場記成 3/31，導致它被算進 2026Q1；之後同一天台灣時間另一筆重複公告也沒被去重。
2. 新加入追蹤、沒有任何歷史紀錄的日本公司（財年 4 月起），冷啟動算出來的窗口 `fiscal` 標籤是 `FY2026Q…`，
   但依 README，2026 年 5 月以後的那幾季應該是 `FY2027`。有歷史紀錄的同一家公司也一樣錯。

---

## 要求

1. 修正程式，使行為符合 `README.md` 的規則。修正要從根因下手，不要只針對 issue 裡的例子寫特例。
2. **不得修改 `tests/` 底下既有的測試檔**；可以新增測試檔（例如 `tests/test_issue42.py`）來覆蓋這次的修正。
3. 修完後執行 `python -m unittest discover -s tests -t .`，全部測試必須通過。
4. 在本資料夾寫 `FIX_SUMMARY.md`，說明：根因（每個問題一段）、改了哪些函式、新增了哪些測試。
5. 只用 Python 標準函式庫。
